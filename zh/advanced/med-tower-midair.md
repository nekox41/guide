# 悬空放置治愈之塔

获得[**螳螂**](https://wiki.warframe.com/w/Mantis)登陆艇，即可使用[**治愈之塔**](https://wiki.warframe.com/w/Mantis#Med-Tower)。

随后配置[**空中支援**](https://wiki.warframe.com/w/Air_Support_Charges)：按 Esc ➛ 轨道飞行器 ➛ 登陆艇 ➛ **空中支援** ➛ 选择治愈之塔。

{% hint style="info" %}
治愈之塔通常生成在地面上，但某些战甲技能或弹丸可以临时充当“地面”，让治愈之塔悬空放置。
{% endhint %}

## Volt

1. 携带一面 Volt 电盾。
2. 使用近战攻击退出曲翼（视角朝上，避免触发震地攻击）。
3. [**瞄准滑翔**](https://wiki.warframe.com/w/Maneuvers#Aim_Glide)。
4. 按下治愈之塔快捷键（[<mark style="color:$success;">**物品快捷键设置**</mark>](../basics/gearwheel-equipment.md)）。

## Nova

1. 使用近战攻击退出曲翼（视角朝上，避免触发震地攻击）。
2. 向下看并[**瞄准滑翔**](https://wiki.warframe.com/w/Maneuvers#Aim_Glide)。
3. 施放[**反物质释放**](https://wiki.warframe.com/w/Antimatter_Drop)（默认按键 2）。
4. 按下治愈之塔快捷键（[<mark style="color:$success;">**物品快捷键设置**</mark>](../basics/gearwheel-equipment.md)）。

## Wisp <a href="#how-to-place-med-tower-for-wisp" id="how-to-place-med-tower-for-wisp"></a>

1. 使用近战攻击退出曲翼（视角朝上，避免触发震地攻击）。
2. 向下看并[**瞄准滑翔**](https://wiki.warframe.com/w/Maneuvers#Aim_Glide)。
3. 施放[**幻影之巫**](https://wiki.warframe.com/w/Wil-O-Wisp)（默认按键 2）。
4. 按下治愈之塔快捷键（[<mark style="color:$success;">**物品快捷键设置**</mark>](../basics/gearwheel-equipment.md)）。

<figure><img src="https://content.gitbook.com/content/SwotjVkQd1faB6N1f6j4/blobs/DlVWOL7TacXZW5B30M1O/image" alt=""><figcaption></figcaption></figure>

## 辐光弩炮（任意战甲）

1. 在希望放置治愈之塔的位置下方，发射[**辐光弩炮**](https://wiki.warframe.com/w/Mandonel)**蓄力弹**；可使用殁世机甲或曲翼枪械设置器。
2. 使用曲翼飞到辐光弩炮的弹道残留上方。
3. 迅速使用近战退出曲翼，然后按下治愈之塔快捷键（[<mark style="color:$success;">**物品快捷键设置**</mark>](../basics/gearwheel-equipment.md)）。
