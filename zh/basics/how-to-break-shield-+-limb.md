# 如何同时击破护盾与关节

## 前提条件

* 使用 1 棱镜（[<mark style="color:$success;">**127 / 177 / 123**</mark>](../builds/amp-builds-modules.md)）。
* 为增幅器正确[<mark style="color:$success;">**配置 MOD**</mark>](../builds/amp-mods-thara.md)。
* [**魔导热熔**](https://wiki.warframe.com/w/Magus_Melt)。
* [**Volt 电盾**](https://wiki.warframe.com/w/Electric_Shield)。
  * 如果不使用 Volt，需要携带曲翼枪械[**辐光弩炮**](https://wiki.warframe.com/w/Mandonel)。

## 操作流程

* 射击关节前，在你与夜灵之间放置一面 [**Volt 电盾**](https://wiki.warframe.com/w/Electric_Shield)。
  * 对水力使叠放 3 面电盾，以应对低概率出现的黄色暴击。
  * 无 Volt 玩法请参阅 → [<mark style="color:$success;">**辐光弩炮**</mark>](../advanced/mandonel-voltless.md)。
* 将魔导热熔叠至 7 层 → [<mark style="color:$success;">**更快地进行虚空弹射**</mark>](how-to-void-sling-faster.md)。
* 触发[**永恒猛攻**](https://wiki.warframe.com/w/Eternal_Onslaught)和[**永恒湮灭**](https://wiki.warframe.com/w/Eternal_Eradicate)赋能。
* 关节解除无敌后，向其射击。
  * 想更快破关，请练习[<mark style="color:$success;">**预判 1 棱镜时机**</mark>](raplak-and-propa-timing.md)。

恭喜！你已经用一发射击同时击破了护盾和关节。
