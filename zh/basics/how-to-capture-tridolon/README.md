# 如何捕获三傻

所有夜灵都遵循相同的基本机制：必须先使用增幅器击破护盾，才能对关节造成伤害。

## 击破夜灵关节

{% hint style="warning" %}
击破关节之前，你需要一个[<mark style="color:$success;">**已充满的气球**</mark>](../lure-management-basic-info.md)。
{% endhint %}

气球充满后，就可以安全地击破夜灵的一个关节。

关节被击破后，夜灵会跪下约 **17 秒**。随后释放 4 道磁力波，每道都会施加[磁力异常状态](https://wiki.warframe.com/w/Damage/Magnetic_Damage)。

使用指挥官保持[**虚空模式**](https://wiki.warframe.com/w/Void_Mode)，以避免受到伤害。

所有配装中都包含[**赋能消磁**](https://wiki.warframe.com/w/Arcane_Nullifier)，可完全抵消磁力异常（+102% 磁力异常抗性）。

{% hint style="danger" %}
如果夜灵倒下时附近没有已充满的气球，它就会传送到随机位置。
{% endhint %}

上述循环需要重复：

* 兆力使：4 次。
* 巨力使和水力使：各 6 次。

#### 恢复阶段

所有关节都被击破后，夜灵进入约 **48 秒**的**恢复阶段**，期间会召唤小夜灵为自己恢复。&#x20;

夜灵倒地后，会以 **2～3 秒**的间隔刷新 **3～4 只小夜灵**。

#### 收尾射击

夜灵重新起身后，即可进行收尾射击（Capshot）：此时全身都能受到伤害，清空剩余生命值即可触发捕获。

{% hint style="info" %}
起身时，夜灵会根据需要继续刷新小夜灵，通常总计 4～6 只。
{% endhint %}
