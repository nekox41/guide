# 气球管理

## 简介

为夜灵诱饵（下文简称“气球”）充能是夜灵狩猎中最基础、也最重要的任务之一。捕获三只夜灵一共需要 8 个已充满的气球：

* [**兆力使**](https://wiki.warframe.com/w/Eidolon_Teralyst)：2 个。
* [**巨力使**](https://wiki.warframe.com/w/Eidolon_Gantulyst)：3 个。
* [**水力使**](https://wiki.warframe.com/w/Eidolon_Hydrolyst)：3 个。

## 获取气球

首先，你需要收集气球。

1. 气球可以在各个 [**Grineer 营地**](https://wiki.warframe.com/w/Plains_of_Eidolon/Map)找到，初始状态为敌对单位。
2. 击倒气球，靠近后按**交互键（默认 X）**打开破解界面。
3. 可以手动破解，也可以**按 Y**直接破解（需要在物品快捷栏中装备[**破解器**](https://wiki.warframe.com/w/Cipher)）。
4. 破解后，气球会变为友方单位，可进行充能并用于捕获夜灵。

## 为气球充能

每个气球需要吸收 3 只小夜灵才能充满。有两种充能方式：

* 击破与气球连接或位于附近的小夜灵的实体，使其被气球吸收（可以看到小夜灵进入气球的动画）。
* 使用指挥官增幅器击杀灵体形态的小夜灵，拾取能量球，再靠近气球为其充能。

最近的小夜灵与气球之间会出现可见的连线。优先击破这只小夜灵，以免未连接的小夜灵逃走。即使先击破了未连接的小夜灵，在它逃走前仍有短暂时间击破已连接的那只，使两只一起被吸收。

**寻找小夜灵的方法：**

* 在地图上飞行寻找。
* 在特定位置定点刷新。
* 利用夜灵恢复阶段在其脚下刷新的小夜灵。

{% hint style="warning" %}
**重要：**战斗中，务必始终让至少一个已充满的气球靠近夜灵。否则，击破关节后夜灵会传送（TP），损失近 30 秒。
{% endhint %}

## 气球管理

气球管理非常重要，你需要随时清楚当前有多少个已充满的气球。

* **开始狩猎**：与兆力使交战前，先充满 1 个气球。
* **兆力使**：捕获需要 2 个已充满的气球。
  * 理想情况下，提前充满至少 3 个气球，便可直接开始巨力使战斗。
* **巨力使**：捕获需要 3 个已充满的气球。
  * 理想情况下，提前充满至少 4 个气球，便可直接继续水力使战斗。
* **水力使**：捕获前，确保有 3 个已充满的气球。
