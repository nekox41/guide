# 水力使出水准备：Volt

## 水力使出水准备：Volt

#### Volt 需要：

* 收集小夜灵，为气球充能。
* 在 4:35 重新放置远点的两面电盾。
* 返回巨力使处并完成收尾射击。
* 返回祭坛，在虫洞前放置电盾。

{% hint style="warning" %}
始终记得后退一些，避免气球生成在虫洞内或水中。
{% endhint %}

* 拾取掉落（刺影 3 技能）。
* 放入碎片。
* 前往 **Volt 出水**[<mark style="color:$success;">**位置-图针**</mark>](loc-pins.md)，击破水力使的出水关节。
