# 巨力使祭坛阶段

## 祭坛阶段：虚空重击时机

掉落气球爆炸时：

* 切换到指挥官。
* 使用力量转移的倒计时判断虚空重击的施放时机：

## 时机

掉落气球爆炸后等待 7 秒，再施放虚空重击。\
如果操作足够稳定，也可以像 Nova 一样用力量转移计时。

{% columns %}
{% column width="75%" %}
* 巨力使出水：力量转移剩余 13 秒。
* 施放虚空重击，切回战甲 → 使用曲翼。
* 放入碎片。
* 直接前往右近点（CR）。
{% endcolumn %}

## 巨力使战斗

* 巨力使的关节阶段与兆力使相同。

## 倒地之后

* 利用定点刷新的小夜灵为气球充能。
* 再获取两个气球。
* 完成巨力使的收尾射击。
* 返回祭坛。
