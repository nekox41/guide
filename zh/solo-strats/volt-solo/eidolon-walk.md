# 夜灵走位

{% hint style="danger" %}
**更新 42：The Shadowgrapher（待确认：更新中文名）**（2026 年 3 月 25 日）

夜灵会忽略地形碰撞，可能深入水中，或走到气球 AI 难以到达的位置。因此，应谨慎连续击破同一侧的多个关节。
{% endhint %}

L / R 表示左／右侧关节【待确认：按玩家视角还是夜灵自身左右区分】。

## 夜灵走位 = 破关顺序

有时收尾射击过快，夜灵虽然被捕获，仍会播放**击杀动画**，并留下**残留碰撞体积**，阻挡你使用**曲翼**闪瞬穿过。

## Volt 单人破关顺序

* **左近点（CL）→ RLLLRR**。
* **右近点／中点／远点（CR / MID / LONG）→** 顺序不限。
