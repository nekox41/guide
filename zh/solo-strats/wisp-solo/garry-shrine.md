# 巨力使祭坛阶段

## **祭坛阶段：虚空重击时机**

掉落气球爆炸的瞬间：

* 切换到指挥官。
* 使用[**能量转换**](https://wiki.warframe.com/w/Focus/Madurai#Power_Transfer)的剩余时间，判断**虚空重击**的施放时机。【待确认：能量转换对应 Power Transfer，专精节点中文名待核对】

## **提前施放虚空重击的时机**

掉落气球爆炸 **7 秒**后，施放**虚空重击**。

如果操作足够稳定：

{% columns %}
{% column width="75%" %}
* 等待能量转换**剩余 13 秒**。

* 施放**虚空重击**，切回战甲。
* 放入**碎片**。
* 使用裂隙涌流传送到左近点。
* 之后的操作取决于巨力使的出水点位。
{% endcolumn %}

## 巨力使战斗

* 使用[<mark style="color:$success;">**辐光弩炮**</mark>](../../advanced/mandonel-voltless.md)，避免 1 棱镜出现黄色暴击。
* 如有生存压力，使用**黯然失色的减伤模式**（夜晚模式）。
  * 连按两次**幻影之巫**，可获得 3 秒无敌。

## 倒地之后

* 利用夜灵脚下刷新的小夜灵为气球充能。
* 再获取两个气球。
* 完成巨力使的收尾射击（黯然失色白昼模式）。
* 返回祭坛。
