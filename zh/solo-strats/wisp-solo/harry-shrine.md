# 水力使祭坛阶段

## 祭坛阶段：虚空重击时机

掉落气球爆炸的瞬间：

* 切换到指挥官。
* 使用[**力量转移**](https://wiki.warframe.com/w/Focus/Madurai#Power_Transfer)的剩余时间，判断**虚空重击**的施放时机。

## 提前施放虚空重击的时机

掉落气球爆炸 **9 秒**后，施放**虚空重击**。

如果操作足够稳定：

{% columns %}
{% column width="75%" %}
* 等待力量转移**剩余 11 秒**。

* 施放**虚空重击**，切回战甲。
* 放入**碎片**。
* 使用裂隙涌流传送到**左近点（CL）**。
* 之后的操作取决于水力使的出水点位。
{% endcolumn %}

## **水力使战斗**

* 对水力使时，必须使用[<mark style="color:$success;">**辐光弩炮**</mark>](../../advanced/mandonel-voltless.md)。
* 如有生存压力，使用**黯然失色的减伤模式**（夜晚模式）。
  * 连按两次**幻影之巫**，可获得 3 秒无敌。

## 水力使倒地后

* 确保所有气球都已充满。
* 水力使倒地后，远离它 30～40 秒，直到即将起身时再靠近，以免气球被摧毁。
* 确保气球已随你一起传送回来。
* 完成最后的收尾射击。
