# 夜灵走位

{% hint style="danger" %}
**更新 42：《绘影者》**（2026 年 3 月 25 日）

夜灵会忽略地形碰撞，可能深入水中，或走到气球 AI 难以到达的位置。因此，应谨慎连续击破同一侧的多个关节。
{% endhint %}

L / R 表示玩家视角的左／右侧关节。

## **夜灵走位 = 破关顺序**

有时收尾射击过快，夜灵虽然被捕获，仍会播放**击杀动画**，并留下**残留碰撞体积**，阻挡你通过**裂隙涌流**传送穿过。

## Wisp 破关顺序

* **左近点（CL）→ RLLRLR** ~~RLLLRR~~。
* **右近点／中点／远点（CR / MID / LONG）→** RLRLRL 或 LRLRLR。
